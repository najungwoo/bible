📚 다양한 학습 모드

  • 빈칸 채우기
  • 구절 암송

📊 학습 관리

  • 일차별 학습
  • 과정별 분류 (1~4과정)
  • 점수 시스템
  • 틀린 구절 복습

💡 편의 기능

  • 3단계 힌트
  • 구절 추가/삭제
  • 일차 관리
  • 글자 크기 조절

🎯 사용 방법

웹 버전

  1. 위의 "웹에서 바로 사용하기" 버튼 클릭
  2. 일차를 선택하고 과정을 선택
  3. 학습 모드를 선택하여 암송 시작
  4. 모바일에서는 홈 화면에 추가하면 앱처럼 사용 가능

Windows 프로그램

  1. 위의 "Windows 프로그램 다운로드" 버튼으로 exe 파일 다운로드
  2. 다운로드한 파일 실행 (보안 경고 시 '추가 정보' → '실행' 클릭)
  3. 일차를 선택하고 학습 시작
  4. 오프라인에서도 사용 가능
