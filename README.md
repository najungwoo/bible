# 말씀 암송 프로그램 (Bible Verse Memorization)

나만의 성경 암송 프로그램을 만들어보세요!

## 다운로드 (Download)
최신 버전은 아래 링크에서 다운로드할 수 있습니다:
[Bible App 다운로드](https://github.com/najungwoo/bible/raw/master/dist/bible.exe)
*(링크 클릭 후 우측의 'Download raw file' 버튼을 눌러주세요)*

## 기능 (Features)
- **일차별 암송**: 매일 새로운 구절을 암송할 수 있습니다.
- **다양한 학습 모드**: 빈칸 채우기, 구절만 보기, 장절만 보기 등 다양한 모드를 지원합니다.
- **나만의 구절 추가**: 원하는 성경 구절을 직접 추가하여 암송할 수 있습니다.
- **파일 공유**: 친구들과 암송 파일을 주고받을 수 있습니다.

## 사용 방법 (How to use)
1. 위 링크에서 `bible.exe`를 다운로드합니다.
2. 프로그램을 실행합니다 (보안 경고가 뜨면 '추가 정보' -> '실행'을 클릭하세요).
3. '관리' 메뉴를 통해 새로운 일차를 만들거나 구절을 추가하세요.
